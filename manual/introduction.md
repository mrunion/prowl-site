# Prowl documentation

Prowl is an open-source game engine built in C# on .NET. It includes a desktop editor for building scenes, working with assets, writing scripts, and testing a game in Play mode. Projects use a GameObject and component model, with C# scripts providing custom behavior.

The engine includes tools for 3D rendering, physics, audio, animation, navigation, input, and UI. The editor brings these workflows together with a Scene view, Game view, Hierarchy, Inspector, Project browser, and Console. You can build standalone desktop applications for Windows, macOS, and Linux.

Prowl is in preview, so features and project formats may change between releases. Use the documentation and editor version that match your project.
